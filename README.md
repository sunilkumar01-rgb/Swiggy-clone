# Swiggy landing page clone

Responsive HTML5/CSS3 recreation based on the two supplied reference screenshots.

## Run
Open `index.html` in a browser. No JavaScript, framework, build step, or server is required.

## Included
- Orange Swiggy-style hero with navigation, location/search fields, and three service cards
- Food and Instamart category rails
- Dineout restaurant cards and app download banner
- Food-delivery city links and multi-column footer
- Responsive layouts for desktop, tablet, and mobile
- Local SVG illustrations in `assets/`

The illustrations are original lightweight placeholders. Replace them with appropriately licensed food photography for an even closer visual match. This is an educational fan-made recreation and is not affiliated with Swiggy.
